# Smart Voice Alarm Suite (Next.js)

Full port of the Smart Voice Alarm HTML suite into Next.js + React + Tailwind.

## Run

```bash
cd web
npm run dev
```

Open **http://localhost:3000**

## Features

- Custom voice alarms (Web Audio + speech synthesis)
- Clock with world timezones
- Timer & stopwatch with laps
- Notes studio (format, read aloud, set as alarm)
- To-do manager with reminders
- Dark / light theme, 12H / 24H
- Data saved in `localStorage`
